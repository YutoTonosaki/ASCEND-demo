# Athlete asset provenance and rights

The runtime asset `assets/athlete.glb` is a new fixed-pose derivative of the
MakeHuman **hm08 base mesh**, using only the source files inventoried and hashed
in `asset-source/provenance.json`. The upstream revision is
`a8bc2d54ff0ac92e78ff71431b1023eda42bf482`.

## Included components

| Component | Author / source | License evidence |
| --- | --- | --- |
| Body, face, hands and feet geometry | MakeHuman hm08; Data Collection AB, Joel Palmius, Jonas Hauquier | `base.obj` header explicitly dedicates the mesh to CC0, September 2020 |
| Fixed adult body target and moderate athletic target blend | MakeHuman; original Manuel Bastioni work, rights transfer and CC0 release identified in each target header | All three `.target` files explicitly state CC0; the average target contains no displacement rows |
| Pose reference and weights, used only while baking | Data Collection AB, Joel Palmius, Jonas Hauquier | `default.mhskel` / `default_weights.mhw` each declare `license: CC0` |
| Compression top and shorts | Original ASCEND prototype derivatives of the same CC0 body surface | New separate meshes generated by our own converter; their added geometry/material definitions are dedicated under CC0-1.0 for this prototype |
| Skin and garment materials | Original constant color/roughness definitions | Original prototype definitions, CC0-1.0; no third-party texture, photograph, logo or material image |

The complete upstream CC0 legal text is retained at
`asset-source/makehuman/LICENSE.ASSETS.md`. Commercial use, modification and
redistribution of these asset components are permitted; attribution is not a CC0
condition. Retain this provenance voluntarily. No third-party community garment,
skin image, hair, shoe or animation is included. The generated body is bald and
barefoot; there are no biometric/user-photo inputs.

[Upstream license and asset/output distinction](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/LICENSE.md).
MakeHuman program code is AGPL. It is **not** copied, imported or installed here.
The converter is newly written Python using standard-library math and a GLB writer;
the JSON rig/weights and OBJ/target files are asset data with the explicit licenses
above. Retaining upstream `LICENSE.md` as evidence does not turn that asset data
into program code.

## Reproducibility and limitations

`python3 tools/prepare-asset.py` verifies every inventoried source hash before
writing the GLB and `assets/manifest.json`. `npm run asset:verify` checks their
hashes and local binary structure. No network access or Blender is needed to rebuild.

The pose is baked. No runtime skeleton, morph targets, animation, fabric simulation
or muscle-development behavior is exported. The top/shorts are simple fitted
prototype garments, not a finished clothing product. Replacement art must undergo
its own component-level rights check; do not treat this provenance as a blanket
license for other MakeHuman community assets.

Rendering libraries have their own code licenses (Expo, React, React Native,
Three.js and React Three Fiber are MIT-licensed projects). Their package notices
remain in the installed dependencies; they are separate from the CC0 model grant.
